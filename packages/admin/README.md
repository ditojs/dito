# Dito.js Admin

Dito.js is a declarative web framework with a focus on API driven development,
built on web standards, MikroORM and Vue.js.

Released in 2018 under the MIT license, with support by https://lineto.com/

Dito.js Admin is a schema based admin interface for Dito.js, featuring auto-
generated views and forms and built with Vue.js

See the [Admin guide](https://github.com/ditojs/dito/blob/main/docs/guide/admin/index.md)
and the [Admin API reference](https://github.com/ditojs/dito/blob/main/docs/api/admin/index.md)
for its views, forms and fields.
